# Biometric-access
Программная система многофакторной биометрической аутентификации пользователя, основанная на совместном использовании технологий распознавания лица и автоматическом сравнении рукописной подписи с применением современных методов компьютерного зрения и глубокого обучения.

# Структура проекта:
1) CNN_extractor.py – скрипт с основными механиками (классом и
функциями) для полного процесса анализа подписей.
2) signature_extractor_weights.pth – зафиксированные веса модели resnet50
для прямого прохода в модели для извлечения признаков из подписи.
3) GUI.py – скомпонованный скрипт интерфейса и моделей распознавания,
анализа и сравнения лиц, и подписей.
