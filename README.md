# Система доступа человека по его биометрии и подписи

Программная система **многофакторной биометрической аутентификации пользователя**, основанная на совместном использовании технологий **распознавания лица** и **автоматического сравнения рукописной подписи** с применением современных методов **компьютерного зрения** и **глубокого обучения**.

Проект демонстрирует подход к построению системы контроля доступа, в которой решение о предоставлении доступа принимается на основе сразу двух независимых биометрических факторов, что значительно повышает надежность аутентификации по сравнению с использованием только одного метода.

---

# Как работает система

Процесс аутентификации состоит из нескольких этапов:

1. Пользователь предоставляет изображение лица.
2. Система выполняет распознавание и сравнение лица с эталонными данными.
3. Пользователь предоставляет изображение своей подписи.
4. Из подписи извлекаются информативные признаки при помощи глубокой нейронной сети.
5. Выполняется сравнение полученных признаков с сохраненным эталоном.
6. На основании результатов обеих проверок принимается решение о предоставлении или отказе в доступе.

Такой подход объединяет преимущества сразу двух независимых биометрических методов и позволяет повысить устойчивость системы к ошибкам и попыткам подделки.

# Структура проекта

В репозитории представлены следующие основные файлы:

### `CNN_extractor.py`

Скрипт с основными механизмами (классом и функциями), реализующими полный процесс анализа и сравнения рукописных подписей.

---

### `signature_extractor_weights.pth`

Зафиксированные веса модели **ResNet50**, используемые для прямого прохода сети и извлечения признакового описания подписи.

---

### `GUI.py`

Основной модуль проекта, объединяющий:

* графический интерфейс пользователя;
* модель распознавания лиц;
* модель анализа подписей;
* механизм сравнения биометрических данных;
* процесс принятия решения об аутентификации.

# Архитектура проекта

Система состоит из двух независимых модулей:

* **Модуль распознавания лица** — выполняет идентификацию пользователя по изображению лица.
* **Модуль анализа подписи** — извлекает признаки подписи при помощи глубокой нейронной сети и сравнивает их с эталоном.

После завершения работы обоих модулей результаты объединяются, и система принимает итоговое решение о предоставлении доступа.

# Цель проекта

Основной целью проекта является разработка прототипа интеллектуальной системы контроля доступа, использующей сразу несколько биометрических факторов для повышения надежности аутентификации.

Проект создавался как **pet-проект** для изучения и практического применения методов компьютерного зрения, глубокого обучения и биометрической идентификации.
